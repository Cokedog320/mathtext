# 2026-07-05 凑十法连线样式修正设计文档

本设计文档旨在记录并规范对 MathText 练习题生成器中“凑十法”方法图示（`MethodDiagram`）下部线条和加号的修正。

## 1. 需求背景

在“凑十法”的图示中，原本的连线设计没有正确连接辅助数字 `10` 与右侧的分成数。用户希望将 `10` 辅助框的底端、右侧分成数框的底端连接到一起，通过加号相加，并最终汇合连接到等号右侧的答案框。

## 2. 设计细节

为了精确还原用户提供的标注样式，仅对 `make-ten` 模式下的 SVG 连线和文字进行调整，其余题型（破十法、平十法等）保持不变。

### 2.1 坐标与布局

- **组件外壳大小**：`w-[180px] h-[160px]`
- **坐标系原点**：
  - HTML 绝对定位组件以图示容器左上角为 `(0, 0)`。
  - SVG 连线容器使用 `absolute inset-0`，其坐标系与容器对齐。
- **关联元素位置**：
  - **被加数 `num1` (例如 7)**: 中心在 `x = 36`。
  - **右分成数 `part2` 框 (例如 3)**: 容器在 `top-[60px] left-[106px] w-[28px] h-[28px]`，其底边中心在 `x = 120`, `y = 88`。
  - **辅助数字 `10` 框**: 容器在 `top-[102px] left-[44px] w-[28px] h-[28px]`，其底边中心在 `x = 58`, `y = 130`。
  - **答案框**: 容器在 `top-[2px] left-[150px] w-[28px] h-[28px]`，其底边中心在 `x = 164`, `y = 30`。

### 2.2 SVG 连线与文字定义

替换 `make-ten` 独有的连接线逻辑：
- **水平汇合线**：从 `x1 = 58`（`10` 框底部中心）连接到 `x2 = 164`（答案框投影的纵轴位置），高度在 `y = 130`。
- **右分成下行线**：从右侧分成数框底端（`x1 = 120`, `y1 = 88`）垂直向下连至水平汇合线（`x2 = 120`, `y2 = 130`）。
- **答案上行线**：从水平汇合线右端（`x1 = 164`, `y1 = 130`）垂直向上连至答案输入框底部（`x2 = 164`, `y2 = 30`）。
- **加号文本**：在 `x = 89`（辅助 `10` 与右分成线的中点附近），`y = 122` 位置渲染字符 `+`。

```xml
<!-- 凑十法 (make-ten) 修正后的连线与符号 -->
<line x1="58" y1="130" x2="164" y2="130" stroke="black" strokeWidth="1.5" />
<line x1="120" y1="88" x2="120" y2="130" stroke="black" strokeWidth="1.5" />
<line x1="164" y1="130" x2="164" y2="30" stroke="black" strokeWidth="1.5" />
<text x="89" y="122" fontSize="20" fontWeight="normal" fill="black" textAnchor="middle">+</text>
```

## 3. 测试与验证

1. **界面预览**：启动本地 Vite 开发服务器，并在浏览器中打开预览页面。
2. **生成验证**：切换题型为“凑十法”，观察图示下方的线条连接是否精确，加号位置是否居中对齐，是否与答案框正确连接。
3. **打印与 PDF 导出**：验证修改后的 SVG 是否能随 html2canvas 及 PDF 完美导出，确保无形变 and 位置偏移。
